# 운영 템플릿

역할 임명, 작업 위임, 상태 보고 및 승인 판단에 필요한 최소 정보를 일관되게 전달할 때 사용한다. 항목의 값이 없으면 추측하지 말고 `미정`으로 표시하고 책임자를 지정한다.

## 시니어 역할 필요성 기록

```markdown
역할명:
책임질 제품 결과:
지금 필요한 이유:
부재 시 위험:
고유 의사결정 권한:
주요 입력:
주요 출력:
의존 역할:
종료 또는 축소 조건:
임명 판단: 승인 | 보류 | 제외
```

## 시니어 역할 헌장

```markdown
제품 목표:
역할과 직급:
책임 영역:
기대 결과:
결정 권한:
범위에서 제외되는 일:
사용 가능한 입력과 프로젝트 자료:
성공 및 승인 기준:
의존 역할과 핸드오프:
보고 형식과 시점:
에스컬레이션 조건:

요청:
1. 담당 영역의 작업을 분해하라.
2. 필요한 하위 작업자 역할과 각 역할의 필요성을 제안하라.
3. 승인 후 각 하위 역할에 작업을 배정하고 결과를 검토하라.
4. 통합 결과, 근거, 위험 및 필요한 제품 수준 결정을 총괄에게 보고하라.
```

## 하위 작업자 작업 브리프

이 브리프는 담당 시니어가 작성하고 배정한다.

```markdown
담당 역할:
작업 목표:
배경과 범위:
입력 자료:
기대 산출물과 형식:
완료 및 품질 기준:
의존 관계:
금지 사항:
보고 대상:
에스컬레이션 조건:
```

## 시니어 상태 보고

```markdown
영역:
상태: 정상 | 위험 | 차단 | 완료
완료된 결과:
검증 근거:
진행 중인 위임:
주요 위험과 대응:
다른 영역과의 의존성:
총괄의 결정이 필요한 사항:
다음 보고 조건:
```

## 총괄 수용 판단

```markdown
검토 대상:
제품 목표와의 정렬:
수용 기준 충족 여부:
기능군 간 영향:
판단: 승인 | 수정 요청 | 보류 | 종료
판단 근거:
시니어에게 돌려보낼 수정 기준:
사용자 승인이 필요한 사항:
```
